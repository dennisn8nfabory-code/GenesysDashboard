🚀 Aan de slag

Welke CSV-bestanden kan ik laden?
Twee types: Interactie-export (Prestaties → Interacties → Exporteren) en Samenvatting agentperformance (Prestaties → Agenten → Exporteren). Beide worden automatisch herkend.
Blijft mijn data bewaard na vernieuwen?
Ja. De tool slaat de data op in localStorage. Na vernieuwen wordt de laatste dataset automatisch hersteld. Klik op het 🗑-icoontje om de opgeslagen data te wissen.
Wat toont het Performance-tabblad?
Tijdmetingen per agent (gesprekstijd, verwerking, wachtstand%) op basis van de agentsamenvatting-CSV, inclusief vergelijking met het teamgemiddelde.

❓ Veelgestelde vragen

Wat is het verschil tussen Gesprekstijd en Verwerking?
Gesprekstijd = pure spreektijd. Verwerking = gesprekstijd + wachtstand + ACW. Een hoge verwerking bij lage gesprekstijd kan wijzen op veel wachtstand of lange ACW.
Wat betekent de ↕ vs. team kolom?
Afwijking van de gem. gesprekstijd t.o.v. het teamgemiddelde. Groen = korter dan gemiddeld, Rood = langer. Dit helpt bij het snel signaleren van uitschieters.
Worden gegevens gedeeld of opgestuurd?
Nee. Alles draait lokaal in de browser. localStorage is alleen beschikbaar op dit apparaat.

🔧 Wat doe je als het niet werkt?

CSV laadt niet

  1. Controleer: moet .csv zijn.
  2. Genesys: "Volledige export" aanstaan.
  3. Nederlandstalige interface vereist.
  4. Probeer één bestand tegelijk.

Data verdwenen na refresh

  1. Controleer: is localStorage ingeschakeld in de browser?
  2. Incognito-modus slaat geen localStorage op.
  3. Herlaad het bestand via drag & drop.
  4. Meld bij Dennis als het structureel fout gaat.

Tool werkt niet

  1. Ctrl+F5 — harde refresh.
  2. Chrome of Edge (versie 90+).
  3. Internetverbinding bij eerste openen.
  4. Screenshot naar Dennis Groothuizen.

Kolommen veranderd

  1. Eerste regel moet beginnen met Volledige export voltooid.
  2. Engelstalige kolommen? NL-interface gebruiken.
  3. Structurele wijziging? Meld bij Dennis.
